## Audit findings on PRs #10 to #12

Ranked by what it would cost Robert to miss.

1. **Existing saves keep the pre-G3 Harrier colors (medium).** `sanitizeWyvern` keeps any valid saved hex, and every save stores the colors it was made with. A save from before G3 still has `#3f7d5a` / `#23453b` / `#d89a5a` and saddle `#7a3a2a`, so the Harrier stays emerald with an oxblood saddle. It compounds in `stableModel.withBreed`: it compares the look against the *new* defaults, so an old-default Harrier counts as customized and switching breeds no longer resets its colors. Fresh saves (the playable artifact link) show the new palette; a local review on an existing save does not. Proposal, not done: a one-time `lookRev` migration like G3c's `lensRev` that swaps colors still equal to the old Harrier defaults for the new ones. It touches save sanitizing (not the schema), inside G3.
2. **Rampart billow seam at world −X (theoretical).** In `SkyDome.ts`, `rampart()` wraps azimuth with `atan(d.z, d.x)`. The head shapes are periodic (`mod(j, cells)`), but `dwFbm3(vec2(u * cells * 9.0, …))` is not, so the billow pattern jumps where `u` goes from 1 to 0, facing world −X (debug `yaw=270`). Captured at golden hour, High, facing yaw 250, 270 and 290 from above Windhaven (`dragon-capture.mjs`, images not committed): **not visible**. The largest column-to-column luminance step across the rampart band at yaw 270 is 0.47 of 255, and not at the wrap. The billow term is a ±15% modulation under 48% fog on the far tier, too faint to show. Theoretical only; worth a one-line fix (wrap `u` into the noise via a circle) only if it is ever seen in game.
3. **Grade keeps a disposed depth texture after High → Medium (low).** `setQuality` disposes the scene target (and its `DepthTexture`) when AO turns off, but `grade.tDepth` / `grade.tAO` keep the old references. `uAOStrength = 0` skips the branch, so nothing renders wrong; three may re-allocate the texture on bind. Fix: reset both to the black texture in the `else` branch of `render()`.
4. **The oxblood saddle left the cloth palette (low).** `PALETTES.cloth[0]` changed from `#7a3a2a` to `#7a5232`. Saves with the old saddle color still load (any hex is valid), but no swatch is selected in the stable. Folded into finding 1's migration.
5. **By design, noted:** `?wyvernTrial=meshy` works in production builds, like `?riderTrial`. The 1.1 MB GLB is emitted by the build but only fetched when the flag is set, and a failed fetch falls back to the procedural Harrier (`Wyvern.ts` catch).

Checked and fine: the lens migration (`lensRev`) only moves saves that are exactly on the old 62° default and never touched the slider; the `wyvernHead` slot defaults to `native` for old saves; the cosmetic unlock (Drake head, 25 feathers) uses the existing requirement types; SSAO targets resize with the canvas and are half resolution; the rampart adds no draw calls (sky-dome shader, early out above 0.14 elevation).
