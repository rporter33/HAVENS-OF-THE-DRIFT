## Findings and changes

- **Volume changes during startup could be lost.** Starting muted and unmuting while the initial 1.5-second master fade was pending allowed its endpoint to overwrite the new setting. Real OfflineAudioContext reproduction: silent output before; after the fix, RMS **−37.5 dBFS**, peak **−14.9 dBFS**. Volume updates now cancel pending automation while retaining the current gain, then glide to the setting. The browser path without `cancelAndHoldAtTime` also passes the same real-mixer regression. [API compatibility reference](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/cancelAndHoldAtTime).
- **Windline actions lacked audio feedback.** Baseline normal-world cast/attach, pull, release and boost created zero Effects-bus voice strips. Short cues now use the existing whoosh, pluck and leather-rustle palette. A presentation observer reads the existing optional equipment contract; no physics, inputs or state mutations. Cast/attach create two strips, pull/release/boost one each. Three repeated cycles each produce exactly five cues; 500 sustained attached updates create zero extra SFX strips.
- **Recall already had feedback.** The rescue swoosh and catch wingbeat both fire; they are retained.
- **Existing mix retained.** Music asset, music trim, wind mappings, breed-mass wingbeats and dragon weight remain unchanged. No new assets, dependencies, purchases, licensing or reference-game audio.
