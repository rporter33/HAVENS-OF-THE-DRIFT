# Dragon Circuit — website storyboard, chapter 01

Exploratory storyboard v1, 2026-10-14. Reference material only; no website or game implementation is authorized by this package.

## Approved direction and requested corrections
- Preserve floating islands, Mediterranean architecture, aerial race rings and their colors. The islands represent the desired game environment.
- Preserve smaller racer scale and monumental elder scale. Frame 02 is a strong tonal reference.
- Refine elder designs against the current game models before treating anatomy as final.
- Dragons: four walking legs plus two separate wings. Wyverns: two hind legs plus wing-arms, no additional forelegs. Some draft images violate this; written anatomy takes precedence.
- Each clan's elder pair resides on a broad tower-top platform above the settlement. Current terrace compositions require revision.
- Five clans: red, green, blue, black, white; one dragon and one wyvern elder per clan, ten elders total.
- Shared culture and architecture with regional accents in clothes, banners and customs, rather than five unrelated civilizations.
- Color philosophies inspired by Magic's color schema; names, symbols, characters and final lore should develop their own identity.
- Chapter sequence, dialogue, human identities, decorative details and mystery reveal remain proposals. Further story brainstorming requested.
- Whether current elders personally witnessed the first cataclysm remains unresolved.

## Proposed interaction
Scroll-driven illustrated chapter with short comic dialogue, subtle clouds/pennants, optional inspectable details and a Red/Blue perspective choice that rejoins. These PNGs are static concept frames, not animations or production layers.
